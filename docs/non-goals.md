# Non-goals

Consequence Rail v0.1 is not:

- a general AI governance, alignment, fairness or model-evaluation framework
- a judge of whether an action is wise, ethical, lawful or socially acceptable
- a policy engine, identity registry or authorization language
- proof that evidence is true or that an action caused an observed outcome
- insurance, escrow, banking infrastructure or a legal warranty
- a guarantee that rollback or compensation will succeed
- a generic API gateway, workflow engine or arbitrary HTTP proxy
- a blockchain, global ledger or consensus network
- a store for raw prompts, private telemetry or sensitive payloads
- a production security product
- a hosted service, support contract or service-level agreement

Deferred work includes persistent transactional storage, external
checkpointing, key rotation, independent evidence adapters, multiple
connectors, multi-organization federation, hardware attestation and
cross-language implementations.

Scope should expand only when a new capability strengthens the exact
action-to-recourse-to-outcome contract.
